# 모임 이벤트 관리 웹 MVP PRD

## 🎯 핵심 정보

**목적**: 모임 주최자가 공지·참여자관리·카풀·정산을 카카오톡·엑셀·계좌이체 등 여러 채널에 흩어서 관리하며 발생하는 번거로움과 누락을 하나의 웹 서비스로 해결한다.
**사용자**: 수영/헬스/친구모임 등 소규모 모임을 정기·비정기로 운영하는 주최자와, 해당 모임에 참여 신청·카풀 좌석 신청·정산 확인을 하는 참여자.

## 🚶 사용자 여정

```
1. 로그인 페이지 / 회원가입 페이지
   ↓ 로그인 성공

2. 모임 목록 페이지
   ↓ "모임 만들기" 클릭            ↓ 모임 카드 클릭

   [주최자 경로]                    [참여자 경로]
   모임 생성 페이지                  모임 상세 페이지
   ↓ 생성 완료                       ↓ "참여 신청" 클릭
   모임 상세 페이지                  참여 신청 완료(pending)
   ↓ 공지 작성                       ↓ 주최자 승인 대기
   ↓ 참여자 승인/거절                내 모임 페이지에서 상태 확인
   ↓ 카풀 등록(선택)                 ↓ 승인 시 approved
   ↓ 비용 항목 등록                  ↓
   ↓ 정산 완료 체크                  카풀 좌석 신청(선택) / 정산 금액 확인
   ↓

3. 내 모임 페이지 (주최한 모임 / 참여한 모임)
   ↓ 모임 클릭

4. 모임 상세 페이지로 복귀 → 위 흐름 반복 (공지 확인, 카풀 확정, 정산 완료 체크 등)
```

- 자동 리디렉션: 비로그인 상태로 `모임 목록/생성/상세/내 모임` 페이지 접근 시 로그인 페이지로 자동 이동(기존 `proxy.ts` 인증 게이팅 재사용).
- 분기점 1: 모임 상세 페이지에서 "주최자 본인 모임"이면 수정/취소/승인·거절/공지작성/비용등록 등 관리 기능 노출, "참여자"면 참여 신청/취소, 카풀 좌석 신청, 정산 확인만 노출.
- 분기점 2: 카풀 확정 시 `confirmed` 건수가 `seat_count`를 초과하면 확정 자체가 차단되고 모임 상세 페이지(카풀 탭)에 그대로 머무른다.

## ⚡ 기능 명세

| -------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | -------------------------------- |
| **F001** | 모임 생성                  | 제목/설명/카테고리(수영·헬스·친구모임·기타)/일시/장소/정원 입력해 모임 생성                                            | 모든 기능의 출발점이 되는 골격 기능                             | 모임 생성 페이지                 |

| **F003** | 모임 상세 조회             | 모임의 제목/설명/카테고리/일시/장소/정원/현재 참여 현황 표시                                                           | 참여 여부 판단과 모든 하위 기능(공지/참여자/카풀/정산)의 진입점 | 모임 상세 페이지                 |
| **F004** | 모임 수정                  | 주최자가 제목/설명/카테고리/일시/장소/정원 수정                                                                        | 일정·장소 변경 등 현실적으로 빈번한 수정 니즈                   | 모임 수정 페이지                 |
| **F005** | 모임 취소                  | 주최자가 모임 상태를 취소로 전환                                                                                       | 모임이 성사되지 않을 때 참여자에게 상태를 알리는 최소 장치      | 모임 상세 페이지                 |
| **F006** | 공지 작성                  | 주최자가 모임에 텍스트 공지를 작성(첨부파일·푸시 없음)                                                                 | 카카오톡에 흩어지던 공지를 한 곳에 모으는 핵심 가치             | 모임 상세 페이지                 |
| **F007** | 공지 목록 조회             | 해당 모임의 공지를 최신순으로 목록 노출                                                                                | 참여자가 공지를 놓치지 않고 확인                                | 모임 상세 페이지                 |
| **F008** | 참여 신청                  | 로그인 사용자가 모임에 참여 신청(동일 모임 중복 신청 불가)                                                             | 참여자 관리의 시작점                                            | 모임 상세 페이지                 |
| **F009** | 참여 승인/거절             | 주최자가 신청 건을 수동으로 승인 또는 거절                                                                             | 정원 관리와 참여자 확정을 주최자가 통제                         | 모임 상세 페이지                 |
| **F010** | 참여자 목록 조회(주최자용) | 주최자가 신청 상태별 참여자 목록 확인                                                                                  | 엑셀로 흩어지던 인원 파악을 대체하는 핵심 가치                  | 모임 상세 페이지                 |
| **F011** | 내가 주최한 모임 목록      | 로그인 사용자가 본인이 주최한 모임 목록 확인                                                                           | 주최자가 여러 모임을 관리할 때 필요한 최소 허브                 | 내 모임 페이지                   |
| **F012** | 내가 참여한 모임 목록      | 로그인 사용자가 본인의 참여 신청/승인 상태를 모임별로 확인                                                             | 참여자가 신청 현황을 한눈에 파악                                | 내 모임 페이지                   |
| **F013** | 참여 취소                  | 참여자가 본인의 참여 신청을 취소                                                                                       | 일정 변경 시 최소한의 자기 관리 수단                            | 모임 상세 페이지, 내 모임 페이지 |
| **F014** | 카풀 등록                  | 운전자가 출발지(텍스트)/출발시간/좌석수를 등록                                                                         | 카풀 조율을 별도 채팅 없이 한 곳에서 처리                       | 모임 상세 페이지                 |
| **F015** | 카풀 좌석 신청             | 참여자가 등록된 카풀에 좌석 신청(신청 1건 = 좌석 1석)                                                                  | 좌석 배정 요청을 구조화                                         | 모임 상세 페이지                 |
| **F016** | 카풀 확정                  | 운전자가 신청 건을 확정. confirmed 건수가 seat_count를 초과하면 확정 자체가 시스템에 의해 차단됨(하드 블록)            | 초과 확정으로 인한 실제 탑승 사고를 원천 차단                   | 모임 상세 페이지                 |
| **F017** | 비용 항목 등록             | 주최자가 항목명/금액/결제자를 등록. 결제자가 여러 명이면 항목 금액을 결제자 수로 1/N 분할해 각 결제자 앞으로 개별 기록 | 계좌이체 내역을 수기로 정리하던 작업을 대체하는 핵심 가치       | 모임 상세 페이지                 |
| **F018** | 참여자별 정산 금액 확인    | 등록된 비용 항목을 참여자 수 기준 1/N으로 자동 계산해 참여자별 분담액 표시                                             | 정산 계산 실수를 없애는 핵심 가치                               | 모임 상세 페이지                 |
| **F019** | 정산 완료 체크             | 참여자별 분담액에 대해 "정산 완료" 여부를 수동으로 체크·보존(비용 항목이 바뀌어도 이 체크만 유지)                      | 실제 송금 여부를 기록해두는 최소 장치                           | 모임 상세 페이지                 |

### 2. MVP 필수 지원 기능

| **사용자 행동** | 기존 값이 채워진 폼에서 제목/설명/카테고리/일시/장소/정원을 수정하고 저장한다 |
| **주요 기능**   | • 기존 데이터가 프리필된 수정 폼<br>• 필수값 검증<br>• **저장** 버튼          |
| **다음 이동**   | 저장 성공 → 모임 상세 페이지(수정된 정보 반영), 실패 → 에러 표시              |
